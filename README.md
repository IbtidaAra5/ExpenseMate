# 💸 ExpenseMate

A low-fidelity mobile expense tracker designed for **university students and young professionals** to easily manage income, expenses, and monthly budgets.

> 🚧 **Project status:** Design / prototype phase. This repository contains the UI/UX design for the app, not a working implementation.

---

## 📌 Overview

Managing money is hard when you're juggling tuition, rent, food, transport, and a small or irregular income. **ExpenseMate** aims to make personal finance simple and approachable with a clean, minimal mobile interface that helps users:

- See where their money is going
- Stay within a monthly budget
- Build better spending habits

## ✨ Key Features

- **Income tracking** – record money coming in (allowance, salary, freelance, etc.)
- **Expense tracking** – log daily spending quickly and categorize it
- **Monthly budgets** – set a budget and keep an eye on how much is left
- **Simple overview** – a clear snapshot of income vs. expenses

## 🎯 Target Users

| User | Why ExpenseMate? |
|------|------------------|
| University students | Track limited allowance and daily expenses |
| Young professionals | Manage salary, bills, and monthly savings goals |
